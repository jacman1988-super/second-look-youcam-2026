PROVENANCE AND LIMITS
The input person is an entirely fictional adult created with OpenAI's image
generation tool without a real person's reference photograph. The garment
reference used for the provider test was an invented synthetic teal dress.
The saved result was generated by YouCam Clothes V4. The concept, interface,
code and documentation used Codex AI assistance.

AI visualization does not establish fit, size, fabric, colour, condition or
authenticity. Check actual garment measurements and seller evidence.
No measured environmental benefit or reduction in returns is claimed.

This viewer is supplementary to the functional local Node prototype. It
does not claim to satisfy judging access requirements on its own. No contest
submission or award is claimed. No files were published by this work.

The confirmed MIT-licensed functional source repository is:
https://github.com/jacman1988-super/second-look-youcam-2026
Live generation in that separate build requires the user's own permitted
API key and appropriate input permissions. This static viewer handles no
credentials and includes no provider calls, connection form or generation.

PRIVACY AND OFFLINE BEHAVIOUR
All images, styles and scripts load by relative local paths. No fonts,
imports, trackers, CDNs, storage, provider requests or external assets load.
A restrictive Content Security Policy blocks connections. The source link
is the only external link; following it intentionally leaves the viewer.
Checklist state and free-text notes remain in page memory until reload or
close. Export creates a local plain-text download containing the checklist
and optional note. It adds no photo URLs. Anything typed into the note will
be included in the downloaded file.
